# Quran Data Kit Example

This example demonstrates how to use the `quran_data_kit` Flutter package.

## Features demonstrated:

1. **Mushaf Page View (`QuranPageView`)**:
   - Interactive full Quran page reading (pages 1 to 604).
   - Dynamic Tajweed font switching and dark/light mode toggle.
   - Word tapping and Ayah long-press gestures.

2. **Continuous Surah Reader (`QuranSurahListView`)**:
   - Vertical continuous Surah view with customizable headers, Basmallah, and verse cards.
   - Verse highlighting (bookmarks/search hits).
   - Inline English translation toggle.

3. **Metadata, Text Search & Random Verse**:
   - In-memory Arabic text search across all 6,236 Ayahs.
   - Surah and page lookups.
   - Random verse generator.

## Running the example

From the `example` directory:

```bash
flutter pub get
flutter run
```
